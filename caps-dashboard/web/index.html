Caps REST API 호출 기록

이 콘솔의 모든 Google Cloud 데이터·통제는 아래 REST 호출로만 이루어집니다 · Authorization 헤더는 BFF 서버에서만 주입

시각메서드엔드포인트상태지연콘솔 동작

    아직 기록된 호출이 없습니다. 화면을 조작하면 BFF가 호출한 Caps API 요청이 실시간으로 표시됩니다.

    PUT /v1/caps/users/{email}

    사용자 예산 한도

    프로젝트별 비용 한도 (USD, 선택)

    POST /v1/users/{email}/block

    사용자 즉시 차단

    차단할 서비스
    차단할 프로젝트

    IAM Deny v2 정책으로 즉시 차단되며, 상태가 전파 중 → 차단 적용됨으로 실시간 추적됩니다.

    POST /v1/users/{email}/unblock

    차단 해제

    해제할 서비스 (모두 해제 시 전체 선택)
    해제할 프로젝트

    PUT /v1/model-rules/default
